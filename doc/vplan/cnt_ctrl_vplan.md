# cnt_ctrl – Direct Test VPLAN

DUT: `cnt_ctrl` · Scope: leaf · Configuration: no parameters · Spec: `doc/spec/architecture/cnt_ctrl_spec.md`, `doc/spec/register_file/register_map.md` (TCR, THCSR)

The testbench acts as the `register` block and `timer_top`: it drives `tim_en`, `div_en`, `div_val`, `halt_req` and `dbg_mode`, and checks `halt_ack`, `cnt_en` and `cnt_clr` in every cycle. The internal divider `div_cnt` is observed only through `cnt_en`.

_VI:_ Testbench đóng vai khối `register` và `timer_top`: lái `tim_en`, `div_en`, `div_val`, `halt_req` và `dbg_mode`, và kiểm `halt_ack`, `cnt_en`, `cnt_clr` ở mọi chu kỳ. Bộ chia nội bộ `div_cnt` chỉ được quan sát qua `cnt_en`.

Cycle notation: `cN` is the clock cycle after the N-th rising edge counted from the start of the sequence. Stimulus changes just after a rising edge; outputs are checked before the next rising edge. `div_cnt` and `tim_en_d` are flip-flops, so a value applied in `cN` affects them from `cN+1`; `halt_ack`, `cnt_en` and `cnt_clr` are combinational. Unless stated otherwise, every input holds its previous value, and every test starts right after reset with `tim_en`=0, `div_en`=0, `div_val`=4'h1 (TCR reset value), `halt_req`=0, `dbg_mode`=0. `div_en`, `div_val` and `dbg_mode` change only while `tim_en`=0, as the register block and the environment require, except where a test states otherwise. With `div_en`=1, `div_cnt` in a cycle is written `d=<value>`; `cnt_en`=1 exactly when `d` = `limit` = 2^`div_val` - 1.

_VI:_ Ký hiệu chu kỳ: `cN` là chu kỳ clock sau sườn lên thứ N tính từ đầu chuỗi. Stimulus đổi ngay sau sườn lên; output được kiểm trước sườn lên kế tiếp. `div_cnt` và `tim_en_d` là flip-flop nên giá trị đặt ở `cN` tác động lên chúng từ `cN+1`; `halt_ack`, `cnt_en` và `cnt_clr` là tổ hợp. Nếu không nói khác thì mọi input giữ giá trị trước đó, và mỗi test bắt đầu ngay sau reset với `tim_en`=0, `div_en`=0, `div_val`=4'h1 (giá trị reset của TCR), `halt_req`=0, `dbg_mode`=0. `div_en`, `div_val` và `dbg_mode` chỉ đổi khi `tim_en`=0, như khối register và môi trường yêu cầu, trừ chỗ test ghi rõ khác. Khi `div_en`=1, giá trị `div_cnt` trong một chu kỳ ghi là `d=<giá trị>`; `cnt_en`=1 đúng khi `d` = `limit` = 2^`div_val` - 1.

## Function coverage

| Function (spec section) | Test |
| --- | --- |
| Reset: `div_cnt` = 8'h0, `tim_en_d` = 0 (Reset) | TC_CNT_CTRL_001, TC_CNT_CTRL_008 |
| DIV_EN = 0: `cnt_en` = `tim_en & ~halted` every cycle, DIV_VAL ignored (Behavior) | TC_CNT_CTRL_002, TC_CNT_CTRL_005 |
| DIV_EN = 1: one `cnt_en` pulse every 2^DIV_VAL cycles, first in the 2^DIV_VAL-th cycle (Behavior) | TC_CNT_CTRL_003, TC_CNT_CTRL_004 |
| `limit` = `(1 << div_val) - 1` for DIV_VAL 0, 1, 2, 8 (Structure) | TC_CNT_CTRL_003, TC_CNT_CTRL_004 |
| `halted` = `dbg_mode & halt_req`, `halt_ack` = `halted` (Structure) | TC_CNT_CTRL_005 |
| Halt: `cnt_en` = 0, `div_cnt` holds, counting resumes at the same phase (Behavior) | TC_CNT_CTRL_005 |
| TIM_EN = 0 or DIV_EN = 0 clears `div_cnt`, priority `div_clr` > `halted` > `match` (Structure, Behavior) | TC_CNT_CTRL_006 |
| `cnt_clr` = 1 for one cycle on TIM_EN 1 -> 0 (Behavior) | TC_CNT_CTRL_007 |

All main functions of the spec are covered. DIV_VAL > 8 is not driven because the register block cannot store it. A `dbg_mode` change while TIM_EN = 1 is not tested: OPEN-001 states it as an environment assumption.

_VI:_ Mọi chức năng chính của spec đều được phủ. DIV_VAL > 8 không được lái vì khối register không thể lưu giá trị đó. Việc `dbg_mode` đổi khi TIM_EN = 1 không được kiểm: OPEN-001 ghi đó là giả định về môi trường.
